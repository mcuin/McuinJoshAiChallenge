Josh.ai Android Dev Challenge 

This app shows the list of NASA Rovers and their data that the API currently supports. When a Rover is selected more details are show about the Rover and their photos on a specific sate can be selected to be viewed. Rover photo dates are based on their landing date and the maximum date provided by the API as to not let a user see a blank screen of photos or have to backtrack years to see any if the Rover has been decommissioned. 

Project can be cloned directly to Android Studio and run on an emulator running API >= 29 after a gradle sync for dependencies. 3rd party libraries can be views in the CREDITS.txt file.
